# Phonebook App

A simple React application that displays names of people and their corresponding phone numbers.

## Running the Application

1. Clone the repository.
2. Navigate to the `part-2/phonebook` directory.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit the local URL displayed in the terminal (typically `http://localhost:5173`).
