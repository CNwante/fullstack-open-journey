# 📚 About Fullstack Open

Fullstack Open is a modern web development course created by the **University of Helsinki** that focuses on building full-stack applications using current industry technologies and practices.

The course covers:

- Modern JavaScript
- React
- State management
- Backend development
- REST APIs
- Databases
- Authentication
- Testing
- GraphQL
- TypeScript
- React Native
- CI/CD
- Containers
- Relational databases

The course emphasizes:

- Practical implementation
- Problem-solving
- Clean code
- Professional development workflows
