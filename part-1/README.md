## Key Takeaways (Engineering Principles)

- **Component-Based Thinking:** React applications are easier to maintain when the UI is divided into small, reusable components.
- **Single Source of Truth:** Maintaining state in one location keeps the UI predictable and consistent.
- **Declarative UI:** User interfaces should be derived from application state rather than manipulated directly.
- **Immutable State Updates:** Creating new state objects or arrays instead of mutating existing ones leads to reliable rendering.
- **Separation of Concerns:** Keeping presentation, state, and business logic separate improves readability and maintainability.
- **Incremental Development:** Building and verifying one feature at a time simplifies debugging and reduces complexity.
- **Effective Debugging:** Systematic use of browser developer tools and logging helps identify and resolve issues efficiently.
