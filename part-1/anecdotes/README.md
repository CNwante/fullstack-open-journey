# Anecdotes App

A simple React application that displays a random programming anecdote, allows users to vote for their favorite anecdote, and highlights the anecdote with the highest number of votes.

## Running the Application

1. Clone the repository.
2. Navigate to the `anecdotes` directory.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit the local URL displayed in the terminal (typically `http://localhost:5173`).
