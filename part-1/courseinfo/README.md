# Course Information App

A simple React application that displays a course name, its individual parts with the corresponding number of exercises, and calculates the total number of exercises using JavaScript's `reduce()` method.

## Running the Application

1. Clone the repository.
2. Navigate to the `courseinfo` directory.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit the local URL displayed in the terminal (typically `http://localhost:5173`).
