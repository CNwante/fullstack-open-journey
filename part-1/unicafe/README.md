# Unicafe

A simple React application that collects user feedback (good, neutral, and bad) and displays real-time statistics, including the total number of feedback responses, average score, and percentage of positive feedback.

## Running the Application

1. Clone the repository.
2. Navigate to the `unicafe` directory.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit the local URL displayed in the terminal (typically `http://localhost:5173`).
